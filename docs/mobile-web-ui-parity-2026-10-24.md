# 移动网页与 Flutter 原生体验对齐

以 2026-10-24 的 `https://yachiyo.hk` 移动页面为参照，保留 Flutter 原生界面、原生 Live2D、站内账号和音频能力。附件网页壳只用于确认参考站点，不作为新的应用实现。

## 页面与操作

- 手机顶部统一为固定的 60 像素圆角导航，页面内容从导航下方开始。通知、头像、应用更新和探索使用网站相同的顺序与图标语言。
- 探索改成导航下方的面板，搜索与大厅／私人居所／广场／主舞台直接可达，次级入口沿用网站分组。大字号允许单列，窄屏内容可滚动；返回和 Escape 关闭菜单并恢复焦点。
- 头像打开账号面板，保留用户中心、成长、通知和附件入口。会话、Live2D、编辑器等原生功能收在“更多 App 功能”；管理员工具继续按当前有效角色显示。会话失效时立即移除私有入口。
- 季节、深浅主题与语言在面板内切换；英文在“更多 App 功能”保留。模态面板打开时隐藏全局引导角色，避免遮住操作。
- 大厅对齐标题层级、插画尺寸、按钮和单行公告；主舞台使用网站标题、筛选和排序样式；广场压缩发布表单、话题入口和三个辅助栏目。
- 登录采用网站的分段登录方式、外置标签和输入图标。第三方登录在常规字号下并排、大字号下上下排列，以便手机首屏操作。密码／验证码登录可通过键盘完成。
- 聊天页在键盘打开时隐藏顶部导航；首次配置增加“稍后设置”，保留重新配置入口。未配置时不再用完整引导覆盖已有聊天记录；跳过引导不配置模型、不发送请求。

## 共用实现与边界

`NativeSiteShell` / `ContentPageShell` 覆盖多数内容页面。账号验证、官方 TTS、QQ 授权、支付、草稿隔离和更新下载仍使用原有实现。

网站 SVG 来自 `TsIcon.vue`，通过 `tool/ui/sync_site_icons.mjs` 同步；其 Lucide / Feather 许可随应用打包。网站来源为 `redchenk/tsukuyomi-space`，本次只读参照其页面、样式和图片，没有修改网站。

本次不提高版本号、不创建发行 tag、不修改更新清单。正式更新继续使用既有阿里云北京分发流程。

## 验证方式

- `flutter analyze` 与 Dart 格式检查。
- 全量 Flutter 回归；额外覆盖 320／390／768 的菜单触控目标、返回焦点、搜索后会话保持、角色和账号变化，以及首次配置暂缓。
- 页面矩阵：28 个页面 × 5 种宽度 × 3 种语言 × 2 种主题；英文大字号。另有顶栏 320–1920 宽度、最高 3 倍文字测试。
- 390×844 与 1280×900 原生截图：大厅、探索／账号面板、登录、主舞台、广场、百科、图库、编辑器、像素工坊、友链与用户中心；示例数据与线上内容明确区分。
- 本机已许可 Cubism SDK 与角色资源用于真实模型截图和 macOS 原生构建。

截图证明所列页面和状态的布局，不等同于全部业务状态与 Android 真机验收。K90 的系统字体、手势返回、中文键盘、QQ 拉起、聊天自动朗读和应用内覆盖安装，需要安装最终 Android 构建后再检查；不会把 macOS 引擎的移动尺寸截图称为 K90 实测。

最终本地结果（应用源码 `b98ffb1`）：静态分析和格式检查通过；`flutter test --concurrency=4 --dart-define=RUN_CUBISM_TESTS=true` 为 1,064 项通过、34 项跳过、0 失败；macOS Debug 构建包含真实角色模型并成功生成。跳过项为需额外外部环境或显式启用的验证，未将其计为通过。Android CI 与 K90 真机验收分别记录，不由本地结果推断。
