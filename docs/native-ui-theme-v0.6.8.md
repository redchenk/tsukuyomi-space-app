# 0.6.8 原生 UI 与网站主题同步

版本：`0.6.8+14 / v0.6.8-beta.1`。视觉基准为网站 [dba4908](https://github.com/redchenk/tsukuyomi-space/commit/dba490894b62cd1799f8d9ab6fbf08199f9a335e) 的 editorial.css、material-components.css、material-pages.css 和樱花原作素材。本次以当前网站设计同步原生客户端，未修改网站源代码或生产数据。

| --- | --- | --- |

主按钮在两个主题中均为 #AC4D6D 白字，悬停 #923D5B；成功、警告和危险保持各主题语义色。`lib/core/site_theme.dart` 集中定义颜色角色和 Material 控件，RoomStyle、Room、Agent、阅读、编辑、设置、登录、社区及管理页共用。卡片 24px、输入 16px、弹层 28px；主按钮仍为胶囊，常规动作至少 44px。焦点、悬停、禁用和选中反馈统一，无新增光晕或位移动效。中文文字沿用系统字体回退，不新增字体依赖。

首次安装默认浅色，与网站一致。设备中明确保存的 light / dark 偏好继续恢复；退出、账号和站点切换不改变设备主题。异步恢复不能覆盖刚做出的选择。

## 原作与页面

浅色背景采用樱花湖畔，暗色采用月下神社，遮罩与网站对应。背景固定在滚动内容外，图片解码按显示尺寸设置上限。导航使用网站的樱月标识；平台启动图标源与网站 icon-512.png 字节一致，各平台尺寸由现有生成脚本派生。

大厅沿用网站的湖畔八千代主视觉。桌面文字 / 插画分区，手机文字和操作在上、245px 插画在下，主体完整可见。新鲜事卡片将封面与正文分开，窄屏采用缩略图和文字并列；原有文章、图库、像素数据及导航保留，真实封面优先。元信息可换行，避免英文放大字体时日期挤出卡片。公告使用独立阅读面。

探索菜单沿用原生已有功能分组和全部入口，更新形状、表面与选中态。键盘、Esc、外部点击关闭、焦点恢复、三种语言、管理员入口权限和减少动画行为保留。Room 场景、Live2D、游戏和绘画工具保持专属布局；文章编辑、协议、审批与账号隔离行为保持原有实现。

## 验证与边界

验证结果见 [本地记录](qa/theme-v0.6.8/local-validation.json)。完整回归 667 项通过；最后的导航和筛选选中色收尾后，再执行最终 UI 回归 63 项，全部通过。格式与静态分析无问题，发布工具 37 项、Agent 工具 3 项通过。

沿用 28 页面 × 5 宽度（360 / 390 / 768 / 1280 / 1920）× 3 语言 × 2 主题，共 840 个首屏与滚动布局场景；英文同时检查 2 倍字体。390px 与 1280px 的两种主题保存 112 张真实字体截图，采样检查大厅、Room、编辑、设置、社区、账户和菜单。截图先等待实际 ResizeImage 资源解码完成。[桌面对照](qa/theme-v0.6.8/compare-hub-desktop.webp)、[手机对照](qa/theme-v0.6.8/compare-hub-mobile.webp) 使用相同窗口尺寸，网站与原生侧使用各自夹具数据。系统字形和内容数据存在差异，因此不作为逐像素相等的声明。

网站截图来自隔离本地预览，数据库和模型 HTTP 服务均为测试夹具。原生完整回归、三桌面固定运行时、五平台构建及下载安装文件校验分别记录；这些结果不代表付费模型、所有 GPU、真实 iPhone 输入或签名验收。iOS 自签及桌面签名限制仍见安装说明。
