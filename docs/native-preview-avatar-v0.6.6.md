# 0.6.6 Markdown 预览与导航头像

本轮修复文章预览采用默认 HTML 样式、登录头像丢失两个问题。版本为 `0.6.6+12 / v0.6.6-beta.1`。

对照原站提交 `291c3874a9420840d5d454f1bd23e62432563e9d` 的 Markdown 解析器、共享样式、editorial 样式、编辑器和 AppShell。上述文件与上一轮 `6487ceb` 相同；隔离网站预览和真实 API 回归仍使用该固定后端，数据为临时 SQLite，未操作生产账号或内容。

## Markdown

编辑预览与文章正文共用 `NativeRichText`，按网站当前样式补齐：

| 内容 | 当前原生行为 |
| --- | --- |
| 标题、段落、列表 | 桌面/窄屏字号、段落间距、行高、H2 分隔线、首标题间距 |
| 引用、行内代码、链接 | 主题色、背景、缩进、链接下划线 |
| 表格 | 外框、圆角、表头、单元格间距、行分隔、对齐、窄屏横向滚动 |
| 提示框 | 网站对应的紫/绿/黄/红强调色、圆角、左侧强调线、标题和正文 |
| 代码块 | 深浅主题均使用网站的深色底、标题栏、13 种语言高亮、原文复制；中文字体回退 |
| 高亮、任务清单 | 五种半透明背景、正文颜色，任务项只显示勾选状态 |
| 折叠、剧透 | 折叠边框与留白；剧透占据原文宽度，可显示后再次隐藏，隐藏文本不进入可访问性朗读 |
| 画廊 | 网站的 560px 断点、双列/单列及 4:3 裁切，点击保留原图查看 |
| 数学、脚注、媒体 | 保留原生公式、脚注跳转、音视频和有界嵌入；非法内容保留可读回退 |

桌面分栏预览高度最多 760px，可独立滚动；完整预览随正文展开。新增三语预览说明和空内容提示。保留 180ms 合并更新、Markdown 缓存、中文 composing、选区、撤销及草稿隔离。

## 头像

登录和 `/api/auth/me` 的 `avatar` 现在保存在 Account 中，并随账号提示恢复。个人中心更新资料时同时发布头像变更，即使昵称没变化也会刷新导航。只更新展示字段，不从资料响应提升角色。

共享导航在 Room、编辑器和其他页面显示 28px 头像；无头像、解码失败或过期登录使用回退。退出、切换账号/站点、过期登录清除旧头像。数据图片的解码字节按组件缓存，避免普通重建时重新创建 MemoryImage；尺寸按显示像素限制。请求头只用于同源图片。

## 验证

- 新增 12 项回归：真实 HTTP 登录/me 字段、只改头像、不可变身份/角色、五种宽度 × 深浅主题的实际图片解码与账号生命周期，以及桌面/手机同一 Markdown 样例。
- 完整本地回归：599 项通过，无跳过；含 840 个整站布局场景、三种语言及放大字体。格式检查、静态分析无问题；发布工具 37 项与运行时工具 3 项通过。
- 既有编辑器回归覆盖中文输入、平台更新、composing、选区、格式和发布；文章回归覆盖代码复制失败、公式错误、容器、脚注、表格及阅读滚动。新增剧透回归验证再次隐藏。
- macOS 实际窗口使用测试站点登录，显示服务端头像；通过个人中心“我的文章 → 编辑”读取同一篇文章，检查原生预览。网站实际浏览器也登录同一测试账号并读取同一文章。
- 中文粘贴的完整内容与预览同步由 Flutter 输入回归验证。计算机操作工具对 macOS 文本框的粘贴曾只改变辅助功能值，未更新 Flutter 模型，因此不将该操作当作实际输入法通过的证据。

## 验收边界

原生字形、子像素排版、展开控件与浏览器仍有系统差异，本轮不宣称逐像素相同。macOS 窗口与组件截图已验证；Windows/Linux/Android 由构建、回归和打包检查验证，不代表全部真机字体、输入法或 GPU 已验收。iOS IPA 仍需自签，未做已签名 iPhone 验收。本轮没有使用用户在线模型密钥。

安装方式见 [安装与配置](release-guide.md)，发布文件、固定 Agent 运行时许可证与校验值随 Release 提供。
