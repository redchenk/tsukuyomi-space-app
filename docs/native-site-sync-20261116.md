## Google 上线依赖

网站当前普通 OAuth 会话绑定在浏览器中，不能直接交给原生 App；Google 也不适合嵌入式授权窗口。因此单独提供了配套路由 `backend/routes/native-auth.js` 和 auth 路由注册改动。它使用现有 Redis store、Google OAuth、站点 session、安全写入校验及限流。

配套接口需要先进入目标网站部署。当前仅完成本地实现及测试，未部署或修改线上账号。测试覆盖请求/密钥校验、浏览器确认、一次性消费、跨账号、跨站请求、取消、过期和禁用账号。登录、绑定与注册仍使用网站原有邮箱核验规则。
