# 设置页登录状态修复

用户反馈通过邮箱或用户名密码登录后，调用官方语音仍提示“请先登录月读空间，再使用站内直供”，点击设置页头像也再次显示登录表单。

已复现两处独立问题：设置页头像始终调用登录对话框；站内直供配置检查把 `settings.demo` 与会话认证混在一起。密码登录后的真实会话在这些复现中仍然有效。另查明 QQ / GitHub 会话导入在 `/api/auth/me` 核实成功后遗漏了 `sessionVerified` 更新，导致授权登录仍无法使用要求认证的功能。

修复后，有效账号的设置页头像进入个人中心，游客或已过期会话继续打开登录。演示模式只控制聊天生成，不作为未登录的依据；保存官方语音保持用户当前的聊天模式，避免顺带启用已保存的付费聊天接口。主动选择站内直供聊天时，仍核实当前账号并加载可用模型。

授权会话通过主站身份核实后立即标记已认证；登录或导入失败的回退同时恢复原来的认证标记。原有主站验证、站点与账号绑定、Cookie 隔离、过期拒绝和语音计费规则保留。

回归使用真实 `SiteClient` 配合模拟 HTTP 响应，覆盖密码登录后保存语音、保留或退出演示模式、有效/游客/过期头像行为、授权导入成功和失败回退；不使用真实账号凭据，不创建付费合成任务。实际账号及设备上的播放效果仍需更新后验收。

本机静态分析通过，8 项新增回归和既有完整测试合计 1,040 项通过、41 项跳过。修复版为 `0.6.29+36 / v0.6.29-beta.1`，更新继续沿用阿里云北京分发服务。
