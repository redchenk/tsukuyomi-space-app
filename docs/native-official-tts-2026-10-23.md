# 原生 App 同步网站官方 TTS

同步依据为主站 `df729dd34c9194b9f467fd7e68b4a3d8321817d6` 的 [官方 TTS 契约](https://github.com/redchenk/tsukuyomi-space/blob/df729dd34c9194b9f467fd7e68b4a3d8321817d6/docs/official-tts.md)与客户端实现。2026-10-23 只读检查线上 `/api/tts/official/status`：HTTP 200，算力在线，语言 `ja`，成功合成 ¥0.05/条，最多 1,000 个 Unicode 字符，缓存保留 24 小时。

## 使用方式

登录主站账号，在「房间设置 → 语音与朗读」选择「官方直供 · 八千代语音」。无需填写 TTS 地址、模型、供应商密钥、参考音频或权重。默认保留用户原来选用的语音渠道，由用户主动切换。

- 「仅保存设置」核实并绑定当前站点及账号，不发起翻译或合成，不收费；离线时仍可保存已有的官方渠道配置。
- 「保存并试听 · ¥0.05」使用固定日文，先保存再合成。未登录、算力离线或语音开关关闭时禁用。
- 聊天朗读沿用网站的日语音色。中文先通过用户当前的聊天模型翻译，翻译按该模型规则计费；算力离线时不先发起翻译。
- 官方语音使用既有网站钱包；超级管理员豁免由服务端核实，不在客户端模拟额度。
- 「支付中心 → 官方语音账单」显示当前账号最近 30 条记录、精确扣费金额及处理中/已合成/失败/缓存过期状态。

## 任务与账号处理

客户端只使用当前站点固定的 `/api/tts/official/status`、`/jobs`、`/jobs/:id` 和 `/jobs/:id/audio`。创建任务的 JSON 仅包含 `text`、`requestKey`。私有请求先通过主站 `me` 核实账号，携带网站 Cookie 与 `X-TTS-Account`；不跟随重定向，也不将 Cookie 或自带供应商密钥交给外部 TTS 服务。

设置试听与聊天播放共享当前主站会话的内存任务缓存。缓存键包含原始文本及账号，保存同一份日文译文、幂等请求编号和服务端任务编号。重复点击、响应丢失、轮询超时和停止后重试都沿用同一请求，避免生成新的收费任务；新任务每 2 秒查询状态，最多等待 110 秒。有效缓存可以在算力离线时继续读取。

失败或过期任务只显示错误，不自动重新生成；用户再次点击才新建任务。停止播放只停止客户端播放与等待，不撤销服务端已接受的合成，也不承诺退款。缓存最长 24 小时、最多保留 100 条内存索引；退出/重新登录、更换站点、应用重启或缓存淘汰后不承诺复用旧任务。语音合成及播放失败均保留已保存的文字对话。

账号或会话发生变化后，旧任务、音频响应和账单结果不得显示到新账号。保存官方设置需要重新绑定当前账号。网站 Cookie 的原有站点绑定、第三方 TTS 选项和各平台音频/Live2D 渲染方式均沿用现有实现。
