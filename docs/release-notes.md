# 月读空间 0.6.38 测试版

- Room 兼容旧版保存的站内直供地址。发送前会核对当前账号及模型能力，支持的 DeepSeek 模型可同时开启深度思考、联网搜索和阅读链接。
- 主动停止或网络中断后，可查看已收到的正文，保留原问题并重试。重新生成失败时，原回答仍保留在聊天记录中。
- 登录失效、余额不足和模型参数错误会分别提供登录、支付中心或聊天设置入口。流式回复改进了中文、表情和跨数据包换行的处理。

Android 手机通常选择 **arm64-v8a**。iOS IPA 与 HarmonyOS HAP 需自行签名后安装。各平台安装说明见附件 `INSTALL.md` 和 `OHOS-INSTALL.md`。
