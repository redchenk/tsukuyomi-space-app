# 月读空间 0.6.37 测试版

- 打开 App 或从网站入口深链唤起时，直接显示私人 Room。移除了开场影片，角色和输入框会直接显示。大厅草稿会带入私人对话。
- 加入与网站共用的月读聊天室。游客可阅读五个频道，登录后可发言、提及八千代和参与每日成长任务，消息及撤回会同步到其他客户端。
- 大厅同步季节首屏和内容预览，宽屏顶栏与手机导航增加聊天室入口。主舞台更新文章列表、推荐续读和跳页，漂流瓶新增拾起后放回，并显示审核状态。
- 像素工坊更新为桌面工具栏与手机触控工作区，支持取色、网格、专注模式、双指轻点撤销、三指轻点重做和最高 1200% 缩放。
- 原生下载中心、Google Play 测试报名、Fushi 授权、测试申请管理和注销处理页面已接入网站接口。

Android 手机通常选择 **arm64-v8a**，可使用原发行签名覆盖升级。iOS IPA 与 HarmonyOS HAP 需自行签名后安装。各平台安装说明见附件 `INSTALL.md` 和 `OHOS-INSTALL.md`。
