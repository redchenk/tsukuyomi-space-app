0.6.31+38 / v0.6.31-beta.1：站内直供同步网站的图片聊天功能。

- 登录后在 Room 设置刷新直供模型，选择标有“文字与图片”的模型并保存，即可直接添加图片提问；无需填写供应商密钥。
- 图片在设备上自动压缩，与文字一起发送，支持流式回复及图片历史同步，按实际 Token 用量使用网站统一余额。
- 设置页和支付中心显示模型的图片能力；切换或手动输入模型时同步能力配置，旧版缓存的“仅文字”配置会在发送时更新。
- 模型不支持图片或登录账号发生变化时停止发送并保留图片草稿，可切换模型或选择已配置的 MCP 识图后重试。
- 更新继续由阿里云北京服务器通过 downloads.yachiyo.hk 分发，下载后校验安装包，沿用既有 Android 发行签名。

普通 Android 手机选择 **arm64-v8a**。iOS IPA 与 HarmonyOS HAP 未签名，需自行签名安装；鸿蒙附件由独立流程追加。本版图片链路已通过离线回归测试，K90 覆盖安装及真实模型图片效果仍需设备验收。安装与配置见 Release 的安装说明。
