0.6.30+37 / v0.6.30-beta.1：原生 App 对齐移动网页的导航与页面体验，让常用操作更便捷。

- 手机顶部使用与网站一致的圆角导航；探索面板集中搜索、大厅、私人居所、广场和主舞台，头像打开账号菜单，常用入口更容易找到。
- 对齐大厅、主舞台、广场和登录页的布局、图标、筛选与按钮；补齐深浅主题、中英日语言、窄屏和大字号适配。
- 密码和验证码登录支持键盘提交；聊天键盘展开时隐藏顶栏，为对话留出更多空间。
- 首次配置可以“稍后设置”，保留重新进入配置的入口；尚未配置模型时仍可查看已有聊天记录。
- 原生 Live2D、官方语音、账号同步、桌面 Agent 和应用内更新继续使用原有实现；原生专属入口集中在“更多 App 功能”。
- 更新继续由阿里云北京服务器通过 downloads.yachiyo.hk 分发，下载后校验安装包，沿用既有 Android 发行签名。

普通 Android 手机选择 **arm64-v8a**。iOS IPA 与 HarmonyOS HAP 未签名，需自行签名安装；鸿蒙附件由独立流程追加。本版不代表 QQ 平台审核通过或小米安装器备案提示已经解除；K90 上的 QQ、自动朗读、系统键盘与覆盖安装仍需真机验收。安装与配置见 Release 的安装说明。
