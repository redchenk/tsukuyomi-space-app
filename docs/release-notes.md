0.6.36+43 / v0.6.36-beta.1 同步网站截至 2026-11-16 的近期功能与内容。

- Room 支持 DeepSeek Flash 应用接口：流式思考、搜索与链接阅读、引用来源、文档、OCR、麦克风转写、带文件的云端历史。站内直供保留身份核验与计费记录，文件失败不会自动重复上传。
- 新增星海来信、每日命题、来信互动与审核，以及游戏中心和可离线保存的五子棋。五子棋聊天使用房间当前连接，发送前可见计费提示。
- 更新春季默认主题、秋季第二版插画、水镜入口、手机底部菜单、像素画工具抽屉与多指缩放、主舞台页码跳转。同步百科、隐私文本、角色资料和中日英词条。
- 海外站可切换英文社区内容与原文，缓存分开保存；私人来信的翻译由用户单独触发。
- 管理终端增加官方 LLM/TTS 配置、DeepSeek 工具费率、每日调用统计和邮件批次预览、确认、进度与停止功能。
- 新增 Google 系统浏览器登录与账号绑定。必须先部署配套网站 `/api/auth/native/*` 接口；旧站点会明确提示暂不可用，密码、邮箱及原有授权方式仍可使用。

本地构建与验证结果、源代码版本和平台限制见 `docs/native-site-sync-20261116.md`。本次代码同步不等于商店审核或公开 Release 已发布。

0.6.35+42 / v0.6.35-beta.1 重做了房间设置入口，并同步网站的语音与角色对话配置。

- 设置首页直接展示八个分类。手机可随时返回全部设置或搜索功能，桌面保留分类侧栏；保留现有模型、记忆、日记、外观、工具与 Live2D 配置。
- 切换分类保留草稿，离开时可保存、放弃或继续编辑。语音服务分为站内直供、个人 API 和本机语音，切换音源也会保留各自草稿。
- 支持个人及官方 Fish Audio，包含八千代音色、模型选择、日语朗读与情感控制。官方服务仍按服务器公布的可用性、价格和账号权限执行；保存配置不发起合成。
- 角色卡和世界书可独立启用、导入、编辑和导出，实际参与聊天请求，数据按站点与账号隔离。同步网站的对话意图规则。
- 保留上一版辉夜快跑的阶段切换与重开修复。

多数 Android 手机请选择 **arm64-v8a** 安装包。其他平台的安装方法见本次 Release 附带的安装说明。iOS 为供自行签名安装的未签名包，鸿蒙仍遵循安装说明中的设备签名步骤。
