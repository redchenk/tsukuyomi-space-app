- 设置首页直接展示八个分类。手机可随时返回全部设置或搜索功能，桌面保留分类侧栏；保留现有模型、记忆、日记、外观、工具与 Live2D 配置。

- 保留上一版辉夜快跑的阶段切换与重开修复。
